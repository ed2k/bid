What this is

A compact in-browser student: it watches the selected teacher bid N generated boards with the same JS engine as the review UI, then trains a small neural network (27 → 64 → 32 → bids) to imitate the teacher's calls from auction features. Deterministic and seeded — identical inputs give identical models. The production 5.5M-param CoT student still trains in Python (refresh_student.py, Loop B); this lab is for fast, local experimentation with any loaded or hand-edited system. Saved student.json files can be reloaded and evaluated here at any time.

Static review UI — engine ported from src/bid/ and cross-validated against recorded traces by tests/web/engine_test.mjs. Refresh the snapshot with python3 -m bid.web_export.
