## Partnership-HCP features (combined_hcp_min/max, partner_hcp_min/max)

Motivation, from §6.65: agreement with Brill is 96.5% PASS / 92.6% L1 but
**22-27% on game and slam**, and game+slam is 25% of data carrying 84% of
the miss mass. Hypothesis: the model cannot combine its own hand with the
range partner has shown, because `partner_last_call` is a bare string
category and a depth-limited tree must burn one split per call value to
approximate "1NT opposite, 25 is enough".

Measured first (before building): across 40,779 traces where partner's call
is invertible, P(Brill bids game) rises monotonically 0% -> 51% with
combined HCP. Signal is real, just not reachable.

Added to `src/bid/features.py`:
- `_partner_hcp_window(partner_calls)` — module-level helper. NT bids are
  precise (1NT 15-17, 2NT 20-21, ...), 1-level suit 11-21, 2C strong 22-37,
  other 2-levels weak 5-10, 3+ preempt 5-10. Passes/doubles/redoubles are
  NOT inverted (ambiguous). Windows intersect in bid order; on
  contradiction the *earlier, wider* commitment is kept rather than
  collapsing to unknown (1H then 3H -> 11-21, not 0-37).
- `partner_hcp_min` / `partner_hcp_max` in `extract_auction_features`.
- `combined_hcp_min` / `combined_hcp_max` in **`extract_all`**, not in
  auction features.

## Section 6.68 -- game-rate bias, tested and refuted (tenth intervention)

Built the held-out set the project lacked: 300 boards at seed 555,
3,006 traces, 4 shards verified DISJOINT, 0 duplicate positions, and
**0 overlap with the 13,450 training boards**. Saved as
`data/brill_traces_holdout555.jsonl`. This is the first genuinely unseen
set; its absence is what caused the 6.64 contamination bug.

`research/brill_rate_bias.py` then found a REAL, significant defect:
- distilled (133k d10): game rate 2.83% vs Brill 5.39% -> bias
  **-2.56pp, t -7.00**, precision 0.729, recall 0.383
- champion: 4.96%, bias -0.43pp, **t -0.84 (n.s.)**, precision 0.248
So the deficit is specific to distillation, and the shape (high precision,
low recall) looks exactly like a threshold miscalibration.

Fix: leaves now carry `class_counts`; `id3_leaf_paths(leaf_margin=)` lets
an unresolved leaf (PASS share < margin) emit its best non-PASS call.
NOT the same as --pass-cap (-1.91): nothing is deleted, no call invented,
confident PASS leaves untouched. Default 0.0 = unchanged behaviour.
`research/brill_leaf_margin.py` fits ONCE and recompiles per margin, so
the sweep costs one 13-min fit instead of six.

The fix works perfectly on its own metric (margin 0.8 -> game rate matches
Brill, bias gone). Graded on the board it is a clean monotone disaster:

    margin 0.5  -0.758 (t -3.15)     margin 0.7  -1.535 (t -4.81)
    margin 0.6  -0.958 (t -3.41)     margin 0.8  -2.850 (t -7.91)

600 boards seed 7, paired vs the margin-0 arm of the SAME fit. Contested
damage ~2x uncontested. Sanity: margin 0.0 vs production control =
+0.200 (t +0.85, n.s.), so the effect is the margin's, not the refit's.

**Conclusion: the timidity is ADAPTIVE.** The model is precise because it
is selective; the games it would add are wrong more often than right.
Brill finds 2x as many games AND is right about them. Champion bids game
at Brill's rate with precision 0.248 (random) and is no better a player.
Game FREQUENCY buys nothing; game ACCURACY is everything. This is also
the mechanism behind --pass-cap's -1.91, now with a dose-response.

Reusable lesson: "the model does X less than the expert" is not evidence
that doing more X helps. Measure the dose-response before believing the
direction. 360 tests pass.

## Section 6.69 -- the 2.6 IMP gap IS competitive interaction

**Key tooling insight: Brill's half of a team match can be replayed from
disk.** Every harvest trace is (deal, seat, ctx, call), so grouping by
deal and ordering by ctx length reconstructs the complete auction remote
Brill played in all four seats. `research/static_team_match.py` replays
that against a local system's self-play, scores both with the same
BiddingArena, and differences them on identical cards. Zero HTTP
requests, 1-3 min, vs ~12,000 requests (~2h) for a live --remote-a run.
Replay verified exact on 60/60 boards. Every future harvest is now a
reusable benchmark.

Static results on 298 held-out boards vs remote Brill:
    brill_distilled  -0.272 (se 0.341, t -0.80)   contested -1.271
    champion_system  +0.225 (se 0.381, t +0.59)   contested -0.150
Both AT PARITY with Brill in isolation. But the two-table team match has
Brill at **+2.63 (t +5.22)** over champion. The designs differ only in
whether the two systems bid against each other => **the gap is
competitive interaction, not contract quality.**

Not fidelity: held-out agreement is HIGHER contested (82.8%) than
uncontested (81.0%). It IS a rate gap -- among 1,685 contested
positions: Brill competes 22.5%, champion 15.3%, distilled 12.3%
(bias **-10.21pp, t -12.15**, the largest deficit measured here).
But the obvious fix was already refuted by 6.68's margin sweep, whose
contested damage (-1.605) was 2x its uncontested damage.

Direction-neutral lever tried: `--group opening_contested` (crosses
is_opening with opponents_bid, 4 groups). CV 82.2 -> **84.2%**.
Team match (objective): -0.130 (t -0.44), contested **+0.032 (t +0.06)**.
Static (proxy): +0.383 (t +1.34), contested **+1.131 (t +2.44)
SIGNIFICANT**, taking contested self-play from -1.121 behind champion to
+0.009.

=> The proxy moved significantly (first board-level significant result
in 11 attempts) and the objective did not move. Self-play competitive
contract-finding and two-system competitive interaction are DIFFERENT
skills. Deliberately did NOT promote: promoting on a proxy just shown to
disagree with the objective is the 6.66 mistake.

**Standing lesson: static_team_match is a diagnostic, never a substitute
for the team match.**
