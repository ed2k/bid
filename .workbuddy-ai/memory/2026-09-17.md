## COMPACT FEATURE ROWS — 3.2x memory, bit-identical fit (committed 91ffa4b)

`featurise` stored a 129-key dict per trace. Measured, fresh process, 200k
rows:
  dict                 3.76 kB/row   717 MB
  __slots__ object     1.19 kB/row   227 MB   <- 3.2x smaller

ID3 only touches rows via `row.get(k, default)` and `row.keys()`, so a
`__slots__` object is a drop-in. Per-row memory is what decides whether the
largest slice fits at all (330k single-process fit died at 21 MB free), so
this buys ~3x more training data for the same peak RSS.

**TRAP (hit it, cost 20 min):** `keys()` must return INSERTION order, NOT
sorted. ID3 breaks information-gain ties by taking the first candidate it
sees => sorted keys silently grow a DIFFERENT tree (held-out agreement
71.1% -> 71.5% on identical data, no error). With insertion order the
emitted DSL is byte-identical (diffed a 296-rule fit).
6 tests in tests/test_brill_distill_rows.py pin this.

## §6.81 — THE GAP IS AN INTERACTION EFFECT (committed dad40f3)

New tool: research/brill_gap_where.py. **Replays Brill's harvested
auctions => Brill becomes a LOCAL system**, attributable + no network +
runnable on held-out boards. (where_lost.py is local-only; this fixes that.)

Both measures on the SAME 1,500 held-out boards (seed 5555, trained on
nothing from it):
    self-play  (brill_gap_where)      -0.063 +- 0.148   t -0.43
    mixed      (team_match --remote-a) +1.780 +- 0.140   t +12.58  for Brill
    => 1.84 +- 0.20 apart, ~9 sigma, IDENTICAL CARDS.

**WHY (the key insight):** self-play compares NS score when EVERYONE plays
ours vs when EVERYONE plays Brill. A symmetric LEVEL bias applies to
whoever holds the hand, so it CANCELS:
    NS has the values: Brill NS game +620 vs our NS partscore +170 -> -10 IMP
    EW has the values: Brill EW game, NS = -620 vs our EW partscore, -170 -> +10
Measured: on the 338 boards where Brill bid game and we stopped in
partscore -> **174 our way, 160 against**, net +0.31 each. The single
biggest contract difference in the data nets to ~zero.
The mixed measure compares each system on the SAME hand => no cancellation.

**THE BIAS IS REAL:** contract class on 1,500 boards
    partscore   us 60.3%   Brill 43.2%
    game        us 37.8%   Brill 51.9%
    slam        us  0.7%   Brill  3.6%
Head-to-head split: contested +2.37, uncontested +1.46 (so NOT just
interference — same cards, we just reach a lower contract).

**EXPLAINS:** why 5 interventions raised fidelity and bought no IMPs (a
model can agree 85% of the time and still be one level light exactly where
the contract is set — fidelity ~orthogonal to a uniform level bias); and
why §6.60 saw "fine in self-play, loses head-to-head" vs champion.

**WARNING FOR THIS REPO:** self-play attribution (where_lost.py AND
brill_gap_where.py) is BLIND to symmetric level bias. Always confirm with
the mixed measure. NB local head-to-head `team_match --a X --b Y` IS a
mixed measure (table 1 X-NS/Y-EW, table 2 Y-NS/X-EW), so §6.76/§6.80's
screenings were valid.

Central number: Brill +1.780 +- 0.140 on held-out boards.
=> Target is a LEVEL/AGGRESSION calibration, not fidelity, not data.
